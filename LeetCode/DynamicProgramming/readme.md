
#### 最外层题目总结

1. Leetcode_198_打家劫舍 -- 固定长度，<font color="purple">下一次位置选与不选</font>，为了最大化，跨度最大为 2；
2. Leetcode_70_climbing_stairs -- 固定长度，明确一次只能走一到两步，求方案数
3. Leetcode_746_使用最小花费爬楼梯 -- 固定长度，明确一次只能走一到两步，求最小值
4. Leetcode_3693_爬楼梯_II -- 固定长度，明确一次可走三步，特殊 cost 规则，求最小值
5. Leetcode_213_打家劫舍_II -- 固定长度，下一个位置选与不选，特殊场景，圈型数组，为了最大化，跨度最大为 2
6. Leetcode_740_删除并获得点数 -- 给定数组，dp 范围为 [0, max_val]，简化为下一个位置选与不选，求最大值；
7. Leetcode_2466_统计构造好字符串的方案数 -- 范围内的最大值，范围内的每个值，都能算前面题目的一个终点；每次跨度（step）不是连续的了；求所有范围内<font color="purple">方案数之和</font>；
8. Leetcode_377_组合总和_Ⅳ -- 给定值（即，固定长度），每次跨度（step）不连续；求组合数（方案数）
9. Leetcode_2266_统计打字方案数 -- 简化后，子问题：固定长度，每次跨度连续（个数有线），求组合数；
10. Leetcode_64_最小路径和 -- 坐标系，横竖正向只能往前，到固定位置；简化后：多维的，连续两个跨度，求最小值；-- 是打家劫舍类似问题的变种，<font color="purple">多维变种</font>
---
+ 1-9: 都是线性 DP, 如果 step 不连续，无法节省空间；连续，可以节省空间；
线性空间上，还是由前面位置的值，决定当前值；
+ 10：可以按线性理解处理，也可以按滚动数组处理（节省空间）；

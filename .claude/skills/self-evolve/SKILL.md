# 自我进化技能

将自动记忆整理为持久化的项目知识。

## 核心能力

| 触发词 | 执行动作 |
|--------|----------|
| "分析记忆" / "review memory" | 分析 MEMORY.md，找出可提升的模式、过时条目、合并机会 |
| "提升规则" / "promote" | 将指定模式从 MEMORY.md 提升到 CLAUDE.md 或 .claude/rules/ |
| "提取技能" / "extract skill" | 将已验证的模式转化为独立技能文件 |
| "记忆状态" / "memory status" | 显示记忆健康报告（条目数、主题分布、建议） |
| "记住" / "remember" | 将重要知识保存到 MEMORY.md |

## 执行流程

### 1. 分析记忆（Review）

当用户说"分析记忆"或类似内容时：

```
1. 读取 MEMORY.md 和 .claude/projects/*/memory/*.md
2. 识别：
   - 重复出现的模式（出现2+次）
   - 过时条目（引用已删除的文件/模式）
   - 可合并的相关条目
   - 适合提升为规则的条目
3. 输出分析报告
```

### 2. 提升规则（Promote）

当用户说"提升 XXX 到规则"时：

```
1. 从 MEMORY.md 找到指定条目
2. 决定提升目标：
   - 全局规则 → CLAUDE.md
   - 作用域规则 → .claude/rules/<name>.md（带 paths 过滤）
3. 转换为规则格式
4. 从 MEMORY.md 移除原条目
5. 确认完成
```

**规则格式示例：**

CLAUDE.md（全局）:
```markdown
## 项目约定
- 使用 pnpm，不要用 npm
- 构建命令：pnpm build
```

.claude/rules/api.md（作用域）:
```yaml
---
paths:
  - "src/api/**/*"
---
- API 测试使用 supertest
- 模拟外部服务使用 msw
```

### 3. 提取技能（Extract）

当用户说"把这个提取成技能"时：

```
1. 识别要提取的模式/解决方案
2. 创建 .claude/skills/<name>/SKILL.md
3. 包含：
   - frontmatter（name, description）
   - 问题描述
   - 解决方案步骤
   - 示例
   - 边界情况
4. 确认技能已创建
```

### 4. 记忆状态（Status）

当用户说"记忆状态"时：

```
1. 统计 MEMORY.md 行数
2. 列出所有主题文件
3. 计算各分类条目数
4. 识别：
   - 超过 200 行（需要整理）
   - 孤立条目（没有链接）
   - 过时条目
5. 输出健康报告
```

### 5. 记住（Remember）

当用户说"记住 XXX"时：

```
1. 确定分类（user/feedback/project/reference）
2. 生成简短的 name（kebab-case）
3. 写入 .claude/projects/*/memory/<name>.md
4. 更新 MEMORY.md 索引
```

## 记忆架构

```
┌─────────────────────────────────────────────────────────┐
│                    记忆层级                              │
├─────────────┬──────────────────┬────────────────────────┤
│  CLAUDE.md  │   MEMORY.md      │   会话记忆             │
│  强制规则    │   学习成果        │   当前对话             │
│  每次都加载  │   前200行加载     │   按需加载             │
├─────────────┴──────────────────┴────────────────────────┤
│              ↑ 提升                ↑ 分析               │
│              │                   │                      │
│              └─── 本技能 ─────────┘                      │
│                  │                   │                   │
│                  ↓ 提取              ↓ 保存              │
├─────────────────────────────────────────────────────────┤
│  .claude/rules/     │    .claude/skills/    │  MEMORY   │
│  作用域规则          │    可复用技能          │  主题文件  │
└─────────────────────────────────────────────────────────┘
```

## 记忆文件格式

### MEMORY.md（索引）
```markdown
- [项目名称](project-name.md) — 项目基本信息
- [构建命令](build-commands.md) — 如何构建项目
- [代码风格](code-style.md) — 编码约定
```

### 单个记忆文件
```markdown
---
name: build-commands
description: 项目的构建和运行命令
metadata:
  type: project
---

构建命令：
- 开发：`pnpm dev`
- 构建：`pnpm build`
- 测试：`pnpm test`

**Why:** 快速参考，避免每次询问
**How to apply:** 用户问如何运行/构建时使用
```

## 提升决策树

```
条目是否反复出现（2+次）？
├─ 否 → 保留在 MEMORY.md
└─ 是 → 是否只适用于特定文件类型？
         ├─ 是 → 提升到 .claude/rules/<type>.md
         └─ 否 → 是否足够复杂成为独立技能？
                  ├─ 是 → 提取为 .claude/skills/<name>/SKILL.md
                  └─ 否 → 提升到 CLAUDE.md
```

## 注意事项

1. **不要过度提升** — 只有真正反复需要的才提升为规则
2. **保持 MEMORY.md 精简** — 超过 150 行时考虑整理
3. **链接相关记忆** — 使用 `[[name]]` 语法
4. **定期清理** — 删除过时条目
5. **技能要完整** — 提取的技能应包含足够上下文独立使用
